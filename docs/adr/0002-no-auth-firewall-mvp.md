# ADR-0002: MVP 不做账号体系，用防火墙 IP 白名单保护

**Status**: accepted

MVP 部署在用户自有的公网 VPS 上，但只服务自家孩子。决定：**不实现任何登录/账号体系**，访问控制靠 VPS 防火墙只放行家庭宽带 IP（Q13 备选的 URL token / Basic Auth / 不设防均被否决；用户外出场景可接受暂时不可用）。

这是**有意的偏差**：公网服务没有认证不是遗漏，未来读代码的人不要"补上"它。将来若向更多孩子开放，需要：简单账号体系、讯飞付费额度（免费 500 次/天不够公开量级）、未成年人个人信息合规审查（个保法）。MVP 阶段的预留方式：数据模型不把"单孩子"假设焊死（练习记录、内容等实体保留可扩展的归属字段），但不提前实现多用户代码。
