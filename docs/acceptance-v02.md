# V0.2 iPad 真机验收清单（票 13）

依据 `.scratch/v02/spec.md` 的 30 条用户故事整理，全部为 **iPad Safari 人工验收**项。
标注 **（需真实凭据）** 的项依赖真实讯飞 LFASR 凭据（上传→转写链路）；
其余项不依赖讯飞，但校对类操作的前置是一条已转写的草稿，真机验收建议在生产凭据下按顺序全跑。

## 〇、准备

- [ ] VPS 已按 `docs/deploy.md` 部署，`https://<域名>` 可访问，pm2 运行中
- [ ] 管理员账号已建（`npx tsx --env-file=.env scripts/create-admin.ts`）
- [ ] `.env` 已配齐 XFYUN（评测）与 LFASR（转写）两套凭据
- [ ] 测试视频就绪：
  - 合法样例：mp4、≤5 分钟、≤200MB、英语语音清晰（最好烧录字幕）
  - 超大样例：>200MB 的 mp4（用于超限提示）
  - 超长样例：>5 分钟的 mp4（用于超限提示）
  - 坏格式样例：.avi 或改后缀的 .txt（用于格式提示）
- [ ] 需要两个家庭账号：管理员先建「家庭 A」「家庭 B」两个家长账号；
  单台 iPad 可用「退出登录」切换账号（或第二台设备/无痕窗口辅助）
- [ ] 记录验收信息：执行人 ＿＿＿ 日期 ＿＿＿ iPadOS 版本 ＿＿＿ 域名 ＿＿＿

## 一、登录 / 退出 / 限速（故事 1、2）

- [ ] 未登录打开 `https://<域名>` → 跳到登录页，看不到任何内容数据
- [ ] 输错密码 → 显示失败提示，不进入
- [ ] 同一邮箱连续失败 5 次 → 提示尝试过多、暂时锁定（15 分钟内正确密码也被拒）
- [ ] 锁定等待过后用正确邮箱+密码 → 登录成功，进入「教材内容」首页
- [ ] 顶部导航显示当前账号邮箱；点「退出」→ 回登录页
- [ ] 退出后直接访问首页 / 自定义内容地址 → 仍被弹回登录页（会话已吊销）
- [ ] 登录后刷新页面 / 关掉 Safari 重开 → 会话保持，不需重新登录

## 二、教材内容与练习，两家庭进度独立（故事 3、17、18、21、22、24）

- [ ] 左侧边栏能在「教材内容 / 自定义内容」间切换（管理员额外有「管理」）
- [ ] 「教材内容」页显示沪教版两个单元卡片（句子数、完成度分布）
- [ ] 进入 U2 → ▶ 开始练这一单元 → 示范自动播放 → 首次弹麦克风权限，允许
- [ ] 读一句 → 出分与星星；「🎧 听我读的」能回放；「↺ 再练一次这句」重录并刷新纪录
- [ ] 自动流转下一句；整单元练完出总星级（需 XFYUN 评测凭据）
- [ ] **家庭 A 练完 U2 后，家庭 B 登录看 U2 → B 的完成度/星级仍是 B 自己的（互不影响）**
- [ ] 断网（飞行模式）读一句 → 提示可重试，联网重试后进度不丢

## 三、自定义内容上传（故事 4、5、30）

- [ ] 「自定义内容」页上传合法样例 → 提交成功，列表出现新草稿
- [ ] 选 >200MB 文件 → 提示「视频超过 200MB，请压缩后再上传」，不产生草稿
- [ ] 选 >5 分钟视频 → 服务端拒绝并提示超时长（列表/页面上有明确错误提示）
- [ ] 选 .avi / .txt → 提示「仅支持 mp4 / m4v / mov 视频」
- [ ] 前置文案正确：页面显示支持格式与上限说明（≤200MB、5 分钟）

## 四、转写状态（故事 6、7）**（需真实凭据）**

- [ ] 上传成功后列表状态为「转写中」
- [ ] 数分钟后（视音频时长）状态自动变「未校对」，无需刷新干预
- [ ] 转写期间 `pm2 restart english-readalong` → 重启后草稿仍自动恢复轮询并完成（不永久卡「转写中」）
- [ ] （可选）临时清空 LFASR 凭据再上传 → 草稿显示「转写失败：生产环境未配置讯飞转写凭据…」
  指向 `.env`（票 13 守卫），配回凭据、删失败草稿重传可恢复

## 五、文本校对（故事 8、9、10、12、28）

前置：一条「未校对」草稿（来自第四节）。

- [ ] 从「未校对」草稿点进文本校对工具
- [ ] 一页显示 10 句，每句有可编辑文本 + 本句片段播放按钮
- [ ] 逐句播放，能对照视频画面里的字幕核对文字
- [ ] 修改某句文本 → 失焦/停顿后自动保存；退出重进修改仍在
- [ ] 删除一句 → 有确认框，确认后句子消失、序号重排
- [ ] 「与下一句合并」→ 两句合为一句，文本与时间正确
- [ ] 「确认本页」→ 本页句子标记已确认，可翻页继续
- [ ] 长视频校对中途退出 → 稍后重进从原进度继续（断点续做）
- [ ] （标准内容草稿，见第七节）校对页显示教材原文参照，
  「采用教材原文」可一键把句子文本替换为教材原文，起止时间与 ASR 文本保留

## 六、切点校对（故事 11、12）

- [ ] 从草稿详情/文本校对切到切点校对工具
- [ ] 逐句播放本句片段，起点/终点边界听感正确
- [ ] 「±0.25 秒」按钮微调某句起点/终点 → 数值变化、播放可验证
- [ ] 改动自动保存；退出重进 → 微调结果保留
- [ ] 「转写中」的草稿不能进切点编辑（提示完成后再来）；已定稿草稿不能再调整切点

## 七、定稿与未校对门禁（故事 13、14、15、23）

- [ ] 未定稿草稿在列表带「转写中 / 未校对」标签，点进的是详情/校对入口而非练习
- [ ] 未定稿草稿**不出现在「教材内容」练习列表**里，孩子无从练到半成品
  （服务端另有练习接口 409 门禁兜底，属 API 层测试覆盖，真机不必构造直接请求）
- [ ] 全部句子校对完 → 点「定稿」→ 状态变「已定稿」
- [ ] 定稿后内容进入「教材内容」列表，可按正常流程练习（示范→录音→出分→总星级）
- [ ] 已定稿内容在站内不能再编辑句子/切点（需重传，spec Out of Scope）

## 八、标准内容制作与管理员功能（故事 25、26、27、28、29）

前置：管理员登录。

- [ ] 管理员侧边栏多出「管理」入口；**普通家长登录后看不到「管理」**
- [ ] 普通家长直接访问 `/admin` → 被拒（无权限）
- [ ] 管理页创建家长账号（邮箱+初始密码）→ 该账号能正常登录
- [ ] 重置某家长密码 → 旧密码失效、新密码可登录
- [ ] 「标准内容制作」页：选教材单元与模块（如 五上-U2 / Story time）→ 上传对应模块视频
  → 出现「转写中」（需真实凭据）
- [ ] 转写完成后进文本校对 → **文本已预填教材原文**，只需处理与音频冲突的句子（需真实凭据）
- [ ] 「采用教材原文」按钮可用（需真实凭据——需先生成标准草稿）
- [ ] 定稿时有确认提示「发布后所有账号可见」→ 确认后状态「已定稿」
- [ ] **所有账号（家庭 A/B）的「教材内容」里都能看到这条新标准内容并能练习**
- [ ] （可选）VPS 上 `ls data/content/standard/` 出现该内容包 JSON（部署不覆盖 `data/`）

## 九、隐私隔离（故事 16、20、24、30）

- [ ] 家庭 B 的「自定义内容」列表看不到家庭 A 的任何草稿或已定稿自定义内容
- [ ] 家庭 B 直接访问家庭 A 的视频地址（`/api/media/<A账号>/…`）→ 被拒绝，不可播放
- [ ] 家庭 B 无法练习家庭 A 的自定义内容（拿内容 id 请求练习 → 拒绝）
- [ ] 两家庭在同一标准内容上的最好成绩/完成度统计互相独立（回看第二节已验，不重复可跳过）
- [ ] 未登录（退出态）直接访问任何内容/视频接口 → 一律拒绝

## 十、iPad 竖屏布局

- [ ] 竖屏持机：首页、自定义页、上传表单、练习页、文本校对页、切点校对页
  均无横向滚动、无元素互相遮挡
- [ ] 播放/录音/±0.25s/确认本页等按钮手指可准确点中
- [ ] 旋转横屏再回竖屏 → 布局自动恢复，不错乱（可选）
- [ ] 弱网（隔一堵墙的 WiFi）下页面仍可用，加载失败有明确提示而非白屏
