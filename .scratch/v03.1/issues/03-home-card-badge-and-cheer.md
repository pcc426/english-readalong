# 03: 教材卡片标签右上角 + 鼓励语收短独占一行

**What to build:** 教材内容首页卡片两处 UI 调整（`src/app/(shell)/page.tsx` 的 `ContentCard`）。

1. **「标准」徽标移到封面右上角**（与自定义列表卡片一致），标题行不再挤占宽度：
   - 徽标 `absolute right-3 top-3`（相对封面容器定位），保留 `shrink-0 whitespace-nowrap` 语义
   - 标题独占整行，长标题不再被挤成多行窄块
2. **鼓励语 ≤10 字（含标点）、不提星级、独占卡片最下一行**：
   - 现状：与「🌟N」并排在同一行、最长 16 字、提到「三星」
   - 目标布局：星数行（🌟N + 「上次练习获得」）→ 最下一行单独显示鼓励语
   - `src/lib/domain/encouragement.ts` 三档文案改为：
     - 开场：`从第一句开始吧！`
     - 进行中：`真棒，继续读！`
     - 满星：`全部满星，太棒了！`

**Blocked by:** None

**Status:** ready-for-agent

## 实现要点

- 鼓励语言长校验写进测试：三档 `length <= 10`（含标点），且都不含「星」以外的星级暗示——即不再出现「三星」字样
- 现有 `encouragement.test.ts` 的「含三星」断言要改（改为断言鼓励继续，或断言长度约束）
- 自定义列表卡片不涉及鼓励语，不改
- 星数行与「上次练习获得」的现有排版保持不变

## 验收

- [ ] 卡片「标准」徽标在封面右上角；长标题占满整行不竖排
- [ ] 鼓励语在卡片最下一行，长度 ≤10 字，无「三星」字样
- [ ] 三档文案单测 + 长度断言；npm test / typecheck / build 全绿
