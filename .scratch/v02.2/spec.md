# Spec: V0.2.2 校对页与练习页左右分栏布局

用户实测 V0.2.1 后确认（2026-10-27）：很多素材视频是**竖版**，上下结构（视频在上、操作在下）导致操作区拥挤、当前句文本被按钮挤在中间难以辨认；练习页出分鼓励语（Excellent!/Good…）出现时视频还会骤缩。两个核心页面统一改为**左右分栏**：左侧视频（竖版可占满整列高度，横版也兼容），右侧操作区；操作内容超一屏时**只在右半侧滚动**。

## 范围（2 票，纯 UI 布局，零 API 改动）

1. **票 01 统一校对页**（`src/app/(shell)/drafts/[id]/proofread/page.tsx`）：左列视频常驻，右列 = 头部（返回/徽标/进度）+ 当前句卡片（文本、教材参照、时点 ±0.25s、插/并/删、确认本句）+ 上一句/下一句导航。票 04 的全部逻辑（insert/merge/delete/confirm/教材采用守卫/返回链接）原样保留，只动布局。→ 实现
2. **票 02 练习页**（`src/app/(shell)/units/[id]/page.tsx` 外壳 + `PracticeFlow.tsx`）：左列视频（REC 角标叠加其上），右列 = 句子导航 chips、三大控制按钮、主卡（当前句文本、录音控制、评分与鼓励语、听我读的/再练一次、开始/收尾）。鼓励语与评分全部在右列展示，**视频列不再因出分而缩放**。右列独立滚动。→ 实现

## 明确不做

- 不加「设为播放位置」按钮（V0.2.1 已否决）
- 不改任何 API / 领域逻辑 / 测试语义；基线 398 测试全绿、typecheck、build 必须保持
- 不引入组件库；Tailwind 布局即可

## 验收

- 768px（iPad 竖屏）与 1200px 桌面：两页均左右分栏、右列独立滚动、视频列大且稳定
- 校对页：确认→插入→拆分→微调→全确认→发布 全流程不受布局改动影响
- 练习页：完整练习一句（示范→录音→出分）流程不变；出分时视频列尺寸不变
