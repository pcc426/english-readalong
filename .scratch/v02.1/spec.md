# Spec: V0.2.1 校对体验迭代

用户实测 V0.2 后确认的修复与改版（2026-10-27 逐条确认）。四张票，全部自包含，实现者无需其他对话上下文。

## 决定

1. **练习录音 dev 模式无法提交（bug）**：`npm run dev` 下录音点「读好了」后提交请求不发出、录音被静默丢弃并自动重录。根因已定位：`PracticeFlow.tsx` 的 `mountedRef` 挂载 effect 缺少设回 `true` 的语句，React 严格模式（Next 15 默认、仅 dev）挂载时预演清理导致恒为 false。生产构建与 iPad/VPS 不受影响。→ 票 01
2. **上传表单 UI**：原生 file input 换中文「选择视频」按钮；选中后文件名高亮；「上传并开始转写」**只要选中视频即亮起**（不等标题，缺标题时提交后走现有错误提示）。`/custom` 与 `/admin/standard` 两处一致。→ 票 02
3. **两个校对工具合并为一个「校对页」**：每句一屏——上方视频（高度受限）+ 下方当前句卡片（文本编辑 + 时点 ±0.25s 微调 + 新增一句/并入上一句/与下一句合并/删除 + 确认本句）。理由：时点校对依赖句子结构定型（先改结构再调时间，否则拆/合会毁掉已调的时间），单页每句一屏让两步在同一处自然完成。任何改动使受影响句回到未确认；**发布门槛 = 全部句子已确认**；切点页（/drafts/[id]/cutpoint）退役。→ 票 03（API）+ 票 04（UI）
4. **明确否决**（不要做）：不引入「设为播放位置」按钮（用户明确偏好 ±0.25s 按钮，不愿拖进度条）；校对页不做时间数字直接输入；不拆分新页面。
