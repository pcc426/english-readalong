## 二、已确认的关键决策（grill 结论）

### 预览

1. 预览**不录音、不调讯飞评分**，目的是检查句子文本与起止时间；视频示范、逐句导航、重播本句可用。
2. 自定义 + 标准两条链路都加预览，复用同一预览页。
3. 预览页顶部有「预览模式」标记和一行提示小字：仅供检查，不录音不评分。
4. 【定稿发布】只在预览页出现（仍保留现有确认弹窗）；可【退回校对】。
5. **UI 收敛，不做服务端预览门禁**——见 [ADR 0005](../docs/adr/0005-preview-gate-ui-only.md)。三处旧发布入口（校对页末句、`/custom/[id]`、标准制作列表）统一改为【去预览】。
6. 预览数据用草稿数据在服务端组装不落盘的 ContentDetail（复用 finalize 的 ms→0.1s 换算）。

### 封面

7. 素材全部是 720×1280 竖屏，封面即 9:16 竖版，不裁剪。
8. 上传定稿管线中用已有依赖 **ffmpeg** 自动截取约 0.5–1.5s 处首帧（避开纯黑开场），输出宽 360px JPEG。
9. 标准 + 自定义卡片都显示封面；自定义上传后即生成。
10. **手动选择/上传封面不在 V0.3**，后续小版本单独做。
11. 现存视频（随代码 2 个 + data/uploads 3 个）由一次性脚本补抽。

### 教材枚举与标题

12. 教材版本枚举只有「沪教版（上教新版）」一项；「牛津上海版」是旧版，不出现。数据结构留扩展位但不做版本切换 UI。
13. 年级学期：数据来自教材 PDF 解析的 JSON 注册表；制作表单的年级/学期下拉**只开放有教材数据的学期**（当前仅五上），其余不出现（不是置灰）。其他年级拿到 PDF、解析入库后自动开放；出现枚举外的新栏目名时再补 `MODULE_KINDS`。
14. 模块沿用教材印刷名，**不归一化**：Talking time / Story time / Reading time / Chant time / Rhyme time / Song time（不是 ChantingTime）。六值经五上数据核对，全部含朗读文本，单词/练习类栏目解析阶段就未纳入。
15. 标题：**课文名（module.title，如 The dragon dance）为主标题**；枚举串 `沪教版五上-Unit2-Story time-7句` 为卡片副标题与练习页副标题；句数每次重新定稿时按实际句数生成。
16. 单元/模块归属必须落进内容包（现在定稿后丢失）。自定义内容标题仍自由文本，不带枚举串。
17. 老标准包 3 个：随代码 2 个按 source 串确定归属，运行时 1 个从 DB 草稿行回填；重生成结构化字段与标题。

### 列表交互（原型选定方案）

18. **教材首页（原型 A）**：顶部工具条＝单元下拉 + 模块下拉；选单元后模块下拉只列该单元有的模块，不选单元可跨单元筛同栏目；默认排序＝单元序号 → 教材数据中的模块顺序。无结果空态卡。
19. 网格＝`repeat(auto-fill, minmax(168px, 1fr))`，1–6 列随宽自适应，不写死列数；间距 gap-4，容器 max-w-7xl。实测：375px→1 列、1024px→4 列、1440px→6 列。
20. **自定义列表（原型 A）**：顶部两个 tab「可练习（已定稿）/ 制作中（转写中+待校对）」，默认可练习；制作中卡片显示「已确认 N/M 句」进度条，转写中不可点。
21. 卡片底部信息加大：总星数 24px 加粗 🌟N + 「上次练习获得」小字；CTA「去练习 →/去校对 →」18px 加粗。「标准」标签 `whitespace-nowrap shrink-0` 固定横向。
22. **上传页（原型 C 分步向导，路由 `/custom/upload`）**：① 选择视频 → ② 填写标题 → ③ 确认并提交；校验沿用现有（mp4/m4v/mov、200MB、5 分钟）。上传成功后 `router.push('/custom?tab=making')`，新内容以「转写中」出现在制作中 tab 第一位；转写完成自动变「待校对」（沿用现有异步转写）。列表页内联表单删除，列表页右上放【＋ 上传视频】。

### 星星统计

23. 教材卡片把现有四个分布胶囊（三星/两星/一星/未练百分比）替换为**最近一次练习获得的总星星数 🌟N**（未练显示「还没练过」）；出分鼓励语保留。
24. 「一次练习」＝一次 PracticeFlow 从 begin 到结束的连续运行（组件 mount/再练一遍整体重开算新 run）；practice_attempts 加 run 归属，统计取该账号该内容最近一个 run 的 stars 之和。中途退出的 run 也算最近一次。
25. 自定义列表卡片同样可显示最近总星数（数据同源），未练不显示。

### 练习页右栏（原型 A，仅调布局/样式，功能不变）

26. 顺序：标题行（主/副标题）→ 待读句卡（含录音/评分/出分全部状态视图）→ 播放控制排（上一句｜暂停/重播｜下一句）→ 主操作排（开始练习 / 听我读）→ 最底部编号句格（mt-auto 沉底，含每句最佳 ★×n）。
27. 「开始练习」实测必须首屏可见（671px 可用高度下按钮底边 ≤ 410px）。
28. 配色对齐 v0.2.x 并按反馈调整：「↺ 再练一次这句」emerald 实心高亮绿；中间重播按钮改名「🔁 再播一遍」——可点击时（录音态重播）高亮黄（amber-400）、播放中为「⏸ 暂停」深灰、无可播内容时置灰禁用；句格读过句子的 ★×n 用 amber-500 加粗。
29. 各按钮既有功能不变（录音、提交、听我读回放、自动跳转等逻辑不动）。

### 状态条 bugfix

30. 校对页提示区域固定高度常驻占位（不再条件渲染塌陷），状态文案切换：保存中… / 所有修改已保存 / **句子已修改，请重新确认** / 保存失败，请重试；「已保存」不做 1.5s 定时消失，常驻到下次编辑。句子被服务端打回 edited 时显示「请重新确认」语义（现状只靠徽标翻转，没有这句文案）。

## 三、明确不做（V0.3 排除项）

- 手动选择/上传自定义封面（后续小版本）
- 五上以外年级、学期的教材数据（拿到 PDF 再说）
- 自定义内容的枚举标题/教材归属
- 预览页评分、预览产生练习记录
- 服务端预览强制门禁（ADR 0005）
- 年级选择器、跨版本教材支持
