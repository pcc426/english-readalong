# 01: 账号、会话与登录

**What to build:** 建立邀请制账号体系的第一条完整路径：一次性 CLI 脚本引导创建首个管理员账号 → 邮箱 + 密码登录 → 服务端会话（HttpOnly cookie，SQLite 存不透明随机 id）→ 退出 → 受保护接口统一鉴权 → 登录失败限速。写 ADR-0003，显式取代 ADR-0002 的"不做登录"决策。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [x] 首个管理员账号由一次性 CLI 脚本引导创建，公网不暴露任何自助创建入口
- [x] 正确邮箱密码登录后获得会话，可读取当前账号
- [x] 错误密码被拒；同一邮箱连续失败触发临时锁定（限速）
- [x] 退出后会话记录被删除并失效，受保护接口返回未登录
- [x] 未登录访问受保护接口被统一拒绝
- [x] ADR-0003 落库，并声明取代 ADR-0002 的无登录部分
