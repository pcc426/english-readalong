# 05: 自定义视频上传与草稿（假转写）

**What to build:** 自定义内容的第一条完整路径：上传表单（家长起标题；大小/时长/格式服务端校验）→ 视频按账号落运行时数据目录 → 创建草稿（转写中）→ TranscriptionService 接口 + 假实现产出句子 → 草稿列表显示「转写中 → 待校对」及句子与起止时间；草稿可删除；自定义视频经鉴权接口播放。

**Blocked by:** 01（账号与会话）、03（首页布局）、04（内容 seam 预重构）

**Status:** ready-for-agent

- [ ] 上传时填写标题；≤200MB、≤5 分钟、mp4/m4v/mov 成功，超限或坏格式被明确拒绝
- [ ] 上传后草稿状态为「转写中」，假转写完成后变为「待校对」并带句子与起止时间
- [ ] 「自定义内容」列表只出现本账号内容，未发布显示明显的「未校对」标签
- [ ] 草稿可被本人删除，删除后列表与磁盘文件一致清理
- [ ] 其他账号访问该账号的视频被拒
- [ ] 上传校验、草稿状态流转、删除、媒体鉴权有路由测试覆盖
