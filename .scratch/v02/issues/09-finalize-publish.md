# 09: 定稿与发布（未校对门禁）

**What to build:** 草稿定稿：校验每句有文本且起止合法 → 生成带 `type`/`owner` 的内容包 → 状态置为已发布；列表标签正确；未发布内容在 API 层禁止开始练习；发布后出现在练习列表。

**Blocked by:** 05（上传与草稿）

**Status:** ready-for-agent

- [ ] 合法草稿可定稿并生成内容包

- [ ] 已发布内容在列表可见，未发布显示「未校对」
- [ ] 未发布内容调用练习接口被拒
- [ ] 其他账号无法定稿或看到该内容
