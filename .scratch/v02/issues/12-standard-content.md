# 12: 标准内容流程（管理员上传、教材原文预填、公开）

**What to build:** 管理员用同一套上传 → 转写 → 校对 → 定稿流程制作沪教版标准内容；上传时选择教材单元与模块，校对页以一次性提取的教材原文预填，管理员与 ASR 结果逐句比对、处理冲突；定稿时标记公开，所有账号在「教材内容」可见。上传时不实时解析 PDF；标准内容视频与自定义视频一致，经鉴权接口提供。

**Blocked by:** 09（定稿与发布）、02（管理员建号）、07（文本校对）、11（教材原文提取）

**Status:** ready-for-agent

- [ ] 管理员上传标准视频并选择单元/模块后，校对页文本已按教材原文预填
- [ ] 定稿标记公开后所有账号可见，普通账号不可修改或删除
- [ ] 标准内容视频经鉴权接口播放（登录后才可播放）
- [ ] 非管理员不能发起标准内容制作
- [ ] 上传流程不依赖运行时 PDF 解析
