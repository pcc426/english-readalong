# Spec: V0.2 邀请制多家庭 + 自定义视频上传

## Problem Statement

V0.1 只服务自家孩子，内容仅限离线制作好的沪教版 U2/U3 两个单元，访问控制靠防火墙 IP 白名单（ADR-0002）。但家长实际需要：① 让跟读练习覆盖孩子正在学的**任意英语视频**，而不只是手工做好的教材单元；② 把工具开放给少量邀请来的家庭，同时让每家上传的内容彼此不可见；③ 有一个登录体系，把上传内容和练习记录绑定到账号。

当前每个新单元都要走"本地脚本 + 发给 Claude 导出 JSON"的一次性流程，家长无法自助使用；也没有任何账号概念，多家庭下"内容私有"无从谈起。

## Solution

升级为**邀请制多家庭**的跟读平台：

- **账号**：家长用邮箱 + 密码登录（管理员手动建号）；一个家长账号对应一个孩子，不做孩子档案与切换。
- **首页**：左侧边栏在「教材内容」（平台公开的沪教版标准内容）与「自定义内容」（本账号上传的内容）之间切换；顶部导航显示账号与退出。
- **自定义视频接入**：家长上传 ≤5 分钟、≤200MB 的英语视频（mp4/m4v/mov，烧录字幕）→ 讯飞录音文件转写（异步）→ 生成带文本与起止时间的句子草稿 → 家长用两个分开的小工具校对（**文本校对**：一页 10 句，对照画面字幕改文本、增删/合并句子；**切点校对**：改造现有"校对模式"，微调起止时间并保存回系统）→ 定稿 → 进入该账号的跟读列表。
- **标准内容**：先用一次性离线工具从教材 PDF 提取 Talking time / Story time / Chant time 等模块的课文文本，结构化存入项目；管理员上传对应模块视频时选择单元与模块，校对文本以该模块的教材原文预填，与 ASR 结果逐句比对处理冲突；定稿时标记为公开，所有账号可见。上传时不实时解析 PDF。
- **状态可见性**：未定稿的内容显示明显的「未校对」标签，可以进入校对，但**不能开始跟读**；只有定稿（已发布）内容才进入正常练习链路。
- **练习归属**：练习记录按账号隔离，每个家庭在标准内容上的进度也各自独立。

## User Stories

1. 作为家长，我想用邮箱和密码登录，以便我的上传内容和练习记录只属于我。
2. 作为家长，我想在顶部导航看到自己的账号并能退出登录，以便在共用设备上控制会话。
3. 作为家长，我想在左侧边栏切换「教材内容」和「自定义内容」，以便快速找到要练的内容。
4. 作为家长，我想上传一段 ≤5 分钟、≤200MB、mp4/m4v/mov 格式的英语视频，以便把孩子正在学的任何材料变成跟读练习。
5. 作为家长，我想在文件过大、时长超限或格式不支持时得到明确的拒绝提示，以便知道该改什么。
6. 作为家长，我想上传后看到「转写中」状态，以便理解系统正在后台处理。
7. 作为家长，我想在转写完成后看到「待校对」状态，以便知道可以回来校对了。
8. 作为家长，我想在校对时一页看 10 句，逐句播放视频片段对照画面字幕，以便高效批量校对。
9. 作为家长，我想修改某一句的文本，以便纠正转写错误。
10. 作为家长，我想删除或合并句子，以便修复切分错误（过度切分或漏切）。
11. 作为家长，我想用播放 + ±0.25 秒按钮微调每句的起止时间，以便每句示范片段干净准确。
12. 作为家长，我想校对进度随时保存、可以中断后继续，以便长视频不用一次看完。
13. 作为家长，我想在全部校对完成后点"定稿"，以便内容正式进入跟读列表。
14. 作为家长，我想让未定稿的内容带「未校对」标签且无法开始跟读，以便孩子不会练到半成品。
15. 作为家长，我想让未定稿内容仍可点进去继续校对，以便随时接着改。
16. 作为家长，我想只看到自己上传的自定义内容，以便其他家庭看不到我的上传。
17. 作为家长，我想看到平台公开的教材内容，以便不用上传也能练习沪教版单元。
18. 作为家长，我想让孩子的练习记录归属在我的账号下，以便进度按家庭统计。
19. 作为家长，我想在内容列表上看到「标准 / 自定义」标签，以便知道内容来源。
20. 作为家长，我想让上传的视频文件只有自己能访问，以便隐私不泄露。
21. 作为孩子，我想在侧边栏选择教材内容或自定义内容，以便练习任意一种。
22. 作为孩子，我想用和 V0.1 一致的流程练习已定稿内容（播放示范 → 录音 → 出分与星星 → 自动流转），以便体验连贯。
23. 作为孩子，我想看到「未校对」标记并无法开始，以便不误入半成品内容。
24. 作为孩子，我想每个家庭在标准内容上的星级进度互相独立，以便不看到别人家的记录。
25. 作为管理员，我想在网页里创建家长账号（邮箱 + 初始密码），以便邀请家庭。
26. 作为管理员，我想重置家长密码，以便帮忘记密码的家庭恢复访问。
27. 作为管理员，我想用与自定义内容相同的上传和校对流程制作沪教版标准内容，并在定稿时标记为公开，以便一套管线服务两种内容。
28. 作为管理员，我想在校对标准内容时文本预填教材原文，以便我只需要处理与音频/字幕冲突的句子。
29. 作为管理员，我想有一个仅管理员可见的管理入口，以便普通家长看不到建号功能。
30. 作为家长，我想服务端也校验文件大小、时长和格式，以便限制不能被绕过。

## Implementation Decisions

### 账号与认证

- 新增 `accounts` 表：`id`、`email`（唯一）、`password_hash`（bcrypt）、`is_admin`、`created_at`。首个管理员账号通过一次性 CLI 脚本引导创建，公网不暴露任何自助创建入口。
- 会话存 SQLite（`sessions` 表：会话 id、账号 id、过期时间），浏览器侧用 HttpOnly + SameSite=Lax + Secure 的 cookie 承载会话 id；退出即删除会话记录。会话 id 为服务端生成的随机不透明 id（opaque id），**不使用签名 cookie/会话密钥**——单进程 + SQLite 的部署形态下吊销能力和简单性全面优于无状态签名方案。
- 登录失败做简单限速（按邮箱/IP 记失败次数并临时锁定），V0.2 不引入验证码。
- 管理员页（仅 `is_admin` 可见）：创建家长账号、重置密码。不做自助注册、不做邮件找回密码（无 SMTP 依赖）。
- 新增 **ADR-0003**：以账号体系取代 ADR-0002 的"不做登录"；防火墙 IP 白名单在多家庭下不再作为主访问控制，改为登录鉴权为主 + 登录限速。ADR-0002 保留为历史决策，在新 ADR 中显式声明取代关系。

### 内容模型

- 内容包 schema 扩展：新增可选 `type: "standard" | "custom"`（缺省视为 standard，既有内容包无需修改即合法）与可空 `owner: string | null`（standard 为 null 且公开；custom 为账号 id 且仅该账号可见）。原 `id/title/source/video/sentences` 保留。
- 内容加载 seam 泛化为「标准目录 + 按账号的自定义目录」合并读取，统一以 content 命名（现有 units 命名在预重构中迁移），避免与教材「单元」术语混淆。
- 自定义内容的 `id` 使用全局唯一 id（UUID 形态），避免与标准内容 slug 冲突。
- 存储边界沿用现有部署形态：
  - 标准内容包随代码部署（只读），标准视频沿用现有素材目录；
  - 自定义内容包与上传视频写入运行时 `data/` 下按账号分目录的位置，部署脚本不覆盖 `data/`。
- 所有视频（标准与自定义）**统一经鉴权接口**按登录与归属校验后提供，不静态公开。
- 草稿（校对中间态）只存 SQLite，不进内容包文件：
  - `content_drafts`：id、account_id、title、type、status（`transcribing` / `proofreading` / `published`）、视频引用、时间戳；
  - `draft_sentences`：draft_id、序号、文本、起止时间（内部按毫秒存，定稿时转换为内容包约定的秒）、校对状态（自动/已改/已确认）。
  - 定稿 = 校验草稿完整性（每句有文本、起止合法）→ 写出内容包 JSON → 状态置 `published`。草稿与已发布分离，保证校对可断点续做、不会产生半成品内容包。

### 教材原文一次性提取（离线工具）

- 教材 PDF 已确认有文字层（100 页，PyMuPDF 可直接抽取），模块标题（Talking time / Story time / Chant time 等）可按页定位。
- 构建一次性离线提取脚本：按单元与模块抽取课文句子，产出结构化数据（单元 → 模块 → 句子列表）存入项目，经人工校对后定稿。
- 提取结果作为标准内容的权威句子清单；ASR 结果只作比对参考。上传标准视频时管理员选择对应单元/模块，系统用该模块文本预填校对页。
- 运行时不做 PDF 解析；PDF 本身仍为本地暂存、不进仓库（提取产物进仓库）。

### 转写缝（TranscriptionService，新增，唯一新缝）

- 仿照现有 ScoringService 的模式：窄接口"输入上传视频 → 输出句子清单（文本 + 起止时间）"；测试用假实现注入，生产用讯飞适配器，调用方只依赖接口。
- 讯飞「录音文件转写」（LFASR）适配器：提交文件 → 轮询任务 → 从结果中逐句取 `bg`/`ed`（毫秒）与 `onebest`（句子文本）。**句子级时间戳为默认返回**，不需要开启 `has_participle`（那是词级）。
- 异步节奏：上传 → 建草稿（`transcribing`）→ 提交转写 → 服务端退避轮询 → 完成后写入 `draft_sentences` 并置 `proofreading`。不做邮件/推送通知。
- 新增 **ADR-0004**：转写引擎选讯飞录音文件转写；否决两个备选并记录理由——① OCR 烧录字幕（抽帧 + PaddleOCR 类工具，VPS CPU 上慢且准确率随字幕样式波动，见调研）；② VPS 自托管 whisper（需升内存、加 Python 与任务队列，运维重）。选择托管 ASR 的理由：已在讯飞体系、按量计费便宜、句子级带时间戳、免运维。
- 视频时长校验用 ffprobe（ffmpeg 已在部署前置依赖中），服务端执行；文件格式与大小同样服务端校验。

### 校对工具（两个，界面分开）

- **文本校对工具（新增）**：分页，默认每页 10 句；每句一行显示可编辑文本 + 该句片段播放按钮，提示对照画面字幕；支持删除句子、与下一句合并；每页可"确认本页"；修改即时保存到草稿。
- **切点校对工具（改造现有"校对模式"）**：保留逐句播放与 ±0.25 秒微调；去掉"导出 JSON 发给 Claude"的一次性流程，改为把起止时间保存回草稿；支持自定义内容视频。
- 两个工具作用于同一草稿，可在之间切换；无 OCR，字幕仅在视频画面中作为人眼参考。

### 界面布局

- 左侧边栏：教材内容 / 自定义内容；管理员额外可见"管理"。
- 顶部导航：当前账号邮箱 + 退出。
- 内容列表卡片带「标准 / 自定义」标签；`transcribing`/`proofreading` 状态带「转写中 / 未校对」标签；未通过（未发布）内容点击进入校对而非练习。

### 练习与记录

- `practice_attempts.owner` 由恒为 NULL 改为写入账号 id；所有练习记录按账号归属。既有 NULL 归属记录一次性迁移到管理员账号名下。
- 星级最好成绩、完成度分布等统计查询增加账号维度：每个账号（家庭）在标准内容上的进度独立计算，自定义内容只对所属账号可见。
- 内容列表接口返回"标准内容（全部）+ 自定义内容（仅本账号）"，并带 `type` 与发布状态。
- 练习提交接口沿用现有契约，增加归属校验（不能练未发布内容、不能练他人的自定义内容）。

### API 契约（扩展现有缝 2）

- 认证：登录、退出、获取当前账号。
- 上传：multipart 上传 → 大小/时长/格式校验 → 建草稿 → 提交转写。
- 草稿：列表（按账号）、详情、批量/逐句更新句子（文本、时间、删除、合并）、定稿。
- 内容：列表（可见性 + 标签 + 状态）、详情；练习提交沿用现有接口并加归属校验。
- 媒体：自定义视频经鉴权接口按归属提供。
- 管理员：建账号、重置密码。

## Testing Decisions

- 只测外部行为，不测实现细节；沿用 V0.1 "只测缝、UI 手工验收"的策略。
- **缝 1（ScoringService）**：不新增测试面，现有测试继续通过即可。
- **新增转写缝（TranscriptionService）**：用假实现跑"上传 → 建草稿 → 转写结果 → 句子落草稿"的完整链路，断言状态流转（transcribing → proofreading）与句子数量/时间正确。讯飞适配器配独立的**集成冒烟测试**（固定小视频 + 真实 LFASR，断言返回句子级文本与起止时间），不在日常测试循环运行，作为适配器验收与漂移检查。
- **缝 2（HTTP API）**：用 API 层 + 临时 SQLite 覆盖：登录成功/失败与限速、未登录拒绝、归属隔离（他人自定义内容不可见/不可练）、上传校验（超大小/超时长/坏格式被拒）、草稿增删改合并与定稿、发布状态门禁（未发布不可练）、标准/自定义可见性、管理员的建号与重置密码权限。
- **内容包 schema**：`type`/`owner` 校验（standard 无 owner、custom 必须有 owner）。
- **媒体鉴权**：未登录或非归属账号访问视频被拒（标准与自定义一致）。
- **UI 不做自动化**：上传、两个校对工具、练习链路继续走 iPad 真机手工验收清单。
- 先例：现有 `api/units/*` 路由测试、`scoring/fake`、内容包 loader 测试。

## Out of Scope

- OCR 提取烧录字幕（明确否决，改用 ASR 转写 + 人工校对）。
- 上传时实时解析 PDF（PDF 解析只做一次性离线提取，产物入库；运行时不解析）。
- 公开自助注册、邮件找回密码（无 SMTP）、验证码/防机器人（仅登录限速）。
- 孩子档案、多孩子切换（V0.2 一个家长 = 一个孩子；数据结构不提前实现 child 维度）。
- 家庭之间分享自定义内容（严格私有）。
- 已发布内容在站内二次编辑（V0.2 要求重新上传；后续可加）。
- IP 白名单/域名备案的最终处理（部署阶段待办，不阻塞开发与调试）。
- 软字幕轨（.srt/.vtt）解析（既然走 ASR，就不单独读取软字幕）。
- 纯音频文件、一条内容挂多个视频。
- 出分语音鼓励（"Excellent!/Good/Try Again!"）：早前讨论过的候选，本 spec 未纳入，可作后续独立小迭代。

## Further Notes

- 讯飞 LFASR 实证结论：句子级 `bg`/`ed`（毫秒）+ `onebest`（文本）默认返回；词级时间戳需 `has_participle=true`（不需要）；时间戳不额外计费，按音频时长计费；新用户礼包最多 50 小时免费（一年）。文档：`https://www.xfyun.cn/doc/asr/ifasr_new/API.html`（字段表）与 `https://www.xfyun.cn/doc/asr/lfasr/Java-SDK.html`（结果解析）。
- 教材 PDF 位于本地 `materials/textbook/`（25MB、100 页、未进 git），已确认有文字层；一次性提取用 PyMuPDF。目录页与页脚会带来布局噪声，提取脚本需过滤，并保留人工校对步骤。
- 部署期待办：域名备案与防火墙/IP 白名单调整合并处理；开发调试可先在现有环境完成，不影响本 spec 的实现与验收。
- 现有切点校对工具（"校对模式"）原本以"导出 JSON 发给 Claude"收尾；本次改造后该流程退役，校对完全站内闭环。
- 存储注意：自定义视频写入 `data/`，单文件上限 200MB，需留意 VPS 磁盘增长；后续可考虑清理/归档策略。
- 需要新增/更新的文档：ADR-0003（账号体系，取代 ADR-0002 的无登录决策）、ADR-0004（转写引擎选型）；GLOSSARY 已补充「标准内容」「自定义内容」及素材/字幕/教材原文的双语境表述。
