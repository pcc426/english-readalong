# V0.4.1 规格：练习结束页与限次收口（V0.4 验收修复）

状态：已实现（2026-11-06），待验收
关联：`.scratch/v04/spec.md`（V0.4 主规格）；本次只修验收发现的问题，不改账本、打卡、曲线口径。

## Problem Statement

V0.4 本地验收（2026-11-06）发现 4 个问题：

1. 练习结束页塞在练习页右栏下方，不是独立页面；未完整轮的「本次句子星 N 颗」容易让孩子误解为已经累计了账号星星。
2. 结束页只有「再练一遍」，没有回列表的次级出口。
3. 教材内容关闭后，自定义内容练习页左上的「单元列表」仍跳 `/units`（教材内容页），落入无内容的错误页面。
4. 打卡日历的 `🌟N` 贴近底部，和「今天」小字或未完成圆点重叠。
5. 本周第 3 次练完后，从结束页「再练一遍」仍能继续练习，绕过 3 次上限；从列表点卡片才会弹限次。

## Solution

- 结束页改为独立路由 `/units/[id]/finish`；练习页练完把本轮汇总写入 `sessionStorage` 后跳转。教材内容与自定义内容共用。
- 结束页底部并排两个按钮：「↺ 再练一遍」（高亮）与「返回列表」（白底浅灰描边）。
- 未完整页删除「本次句子星 N 颗」，只保留读了 X/Y 句与不能累计星星的标注。
- 「再练一遍」先检查 `weeklyRuns >= 3`：达到上限弹既有 `WeeklyLimitModal`，否则整页重开练习页并重新读取本周次数。
- 练习页左上返回链接按内容类型区分：自定义内容回 `/custom`（「‹ 自定义内容」），标准内容回 `/units`（「‹ 单元列表」）；预览模式仍由调用方传入校对页地址。
- 日历格改为三段式布局：日期行 / 星级居中区 / 底部预留「今天」行，星级与今天标记不再重叠。

## Implementation Decisions

- 结束页数据形状 `FinishPayload` 与展示映射收敛在 `src/app/(shell)/units/[id]/finish-summary.ts`（纯函数，带单元测试）。
- `PracticeFlow` 在 `state.step === "finished"` 时用 `router.replace` 跳转，避免浏览器返回又回到已结束的练习页；严格模式下用 ref 保证只跳一次。
- 直接访问结束页且无本轮结果时，显示「没有找到这次的练习结果」+「返回列表」兜底。
- 不改变评分、账本写入、baseline、打卡与曲线逻辑；不改变即时评分卡和句格 UI。
- 部署与 V0.4 相同，无新增迁移或环境变量。

## Testing Decisions

- `finish-summary` 单元测试：完整/翻倍/未完整/服务端值缺失的 awarded 计算、上限判断、返回列表去向、sessionStorage 键隔离（7 例）。
- 回归：`npm test` 668 全绿，`npm run typecheck`、`npm run build` 通过。
- 手工验收（localhost:3000 已实测）：
  - 成长页日历星级居中、今天不重叠；
  - 结束页完整/翻倍/未完整/限次四态；
  - 自定义内容练习页返回链接回 `/custom`，标准内容回 `/units`；
  - 本周第 3 次练完后「再练一遍」弹限次弹窗。

## Out of Scope

- 修改星星账本、完整练习判定、翻倍规则、每周上限次数。
- 结束页展示逐句星星明细（V0.4 已决定不显示句子星合计）。
- 改动 V0.4 的路由与导航结构。
