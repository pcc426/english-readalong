# V0.4 需求决策记录（Grilling）

状态：记录于 2026-11-05；原型 A 方案已确认；spec 待写。
范围：v0.4 激励体系——我的成长页、星星账本、打卡月历、余额曲线；宠物延后到 0.4.x。

## 1. 背景

V0.4 开始完善孩子的激励体系。最初的四个需求是「今日任务看板、每月打卡记录表、每月星星积累曲线、账号星星积分体系」，后续扩展是成长小宠物。

Grilling 后范围收敛为：

- 不做「今日任务看板」，孩子/家长自行决定每天练什么。
- 新增「我的成长」一级页面，作为登录后的默认首页。
- 建立账号星星账本，支撑打卡月历、余额曲线和后续宠物成长。
- 宠物只预留数据（总星数/账本），UI 和动画在 0.4.x 单独做。

## 2. 最终决策

| # | 决策点 | 结论 |
|---|---|---|
| D1 | 今日任务 | 不做；不做任务生成、任务完成判定和家长布置入口 |
| D2 | 积分单位 | 按「一次完整内容练习」入账，不按单次录音或单句直接累加 |
| D3 | 完整练习 | 同一 run 内，内容的每一句都至少成功录音评分过一次；跳过、没录、评分失败未补都不算 |
| D4 | 每周上限 | 同一内容每周最多 3 次完整练习；第 4 次起硬拦截；入口不置灰，点击弹提示；服务端也拒绝 |
| D5 | 打卡 | 北京时间某天至少完成一次完整练习；同一天多次完整练习累计当天星数 |
| D6 | 未完成练习 | 不产生账号星星、不算打卡、不占用每周 3 次；结束页照常显示句子星并标注「未读完所有句子，不能累计星星🌟哦！」 |
| D7 | 翻倍 | 本轮三星句数 ≥ `round(总句数 × 0.9)` 时，本轮星星 ×2；账本记翻倍后的最终星数 |
| D8 | 初始星星 | 按「每个内容的历史最好星」一次性折算；只折算星星，不补历史打卡日 |
| D9 | 曲线 | 当月每日账号星星余额（含初始星星）；当月只画到今天，过去月份画满整月 |
| D10 | 上线前月份 | 只显示日历和「打卡记录从 2026 年 11 月开始」，不画曲线 |
| D11 | 月历 | 打卡日显示 ✓ + 当天星数；练过但未完成显示浅色圆点、不显示星数；没练空白 |
| D12 | 连续打卡 | 从今天（若今天已打卡）或昨天往前，数连续有完整练习的天数 |
| D13 | 页面 | 根路径 `/` 改为「我的成长」，所有账号登录后默认落这里；教材内容列表移到 `/units` |
| D14 | 侧边栏 | 我的成长 → 教材内容（可见时）→ 自定义内容 → 管理（管理员） |
| D15 | 次数提示 | 平时不在列表/详情显示「本周已挑战 N/3」；只在用完后弹窗 |
| D16 | 等级 | v0.4 只显示累计星星；等级、称号、宠物阶段后续版本再定 |
| D17 | 时间口径 | 日/周/月边界固定北京时间（UTC+8）；周界为周一 00:00 到周日 24:00 |
| D18 | 账号维度 | 一个家长账号 = 一个孩子；不做孩子档案/多孩子切换 |
| D19 | 内容范围 | 今日任务不做了，所以不再区分标准/自定义；成长页按账号账本统计，不依赖内容类型 |
| D20 | 弹窗 | 用站内自绘弹窗组件，不再用浏览器原生 `alert/confirm`；v0.4 至少用于超次数提示 |
| D21 | 句格显示 | 保持现有 UI：句格显示每句历史最高句子星；即时评分卡显示本次录音的句子星 + 最好成绩；不额外加提示（已确认） |
| D22 | 内容卡片 | 改为读账本最近一次完整练习的入账星（含翻倍）；从未完整练过显示「还没完整练过」（已确认） |
| D23 | 初始星星日期 | 记在上线当月 1 日，作为当月曲线起点；上线前的旧数据不补打卡（已确认） |
| D24 | 旧数据归属 | `owner` 为 NULL 的账号体系前记录并入管理员账号，与 v0.2 迁移口径一致（已确认） |

## 3. 分轮记录

### 第一轮

**Q1 星星怎么赚**
最初选项是「每次提交累加 / 每句历史最好星 / 每天每句最好星 + 打卡任务奖励 / 每轮最高星」。用户否定了按句累加，改为：

- 按一条内容的完整练习累计。
- 同一内容一周最多重复 3 次，3 次都累计，不取最高。
- 超过 3 次提示（最终文案见 Q9/Q17：这个内容本周已经挑战 3 次啦，下周再来挑战，先试试其他内容吧）。
- 句子级星级逻辑沿用现有代码。

**Q2 什么算打卡**
原选项 A 任意录音 / B 完成任务 / C 获得 N 星 / D 完整练完一条。用户选 D，并在第二轮明确为「同一 run 内每句都录过」。

**Q3 今日任务**
用户考虑后决定不做：自定义内容数量各账号不一致，先让孩子/家长自行决定每天读什么。

**Q4 历史练习**
用户选 B，按新规则计入作为 baseline；已有星星的账号初始值不为 0。

**Q5 页面**
用户选择新增「我的成长」一级页面，登录后默认进入，放在侧边栏第一项。

**Q6 范围**
用户选 A：四项全做（后来剔除今日任务），宠物只预留数据；宠物 UI 放到 0.4.x，先调研动效实现方式。

**Q7 教材可见性**
随今日任务取消而消失；成长页不依赖内容类型。

**Q8 时间/账号**
日期边界用北京时间；保留一个家长账号对应一个孩子。

### 第二轮

**Q8 完整练习判定**
用户选 A：同一轮内每句都至少成功录音一次。特别强调：3.12 读完整条，3.13 只读前 6 句，3.13 不算打卡——即使这些句子历史上都被评过分，最新一轮不完整就不算。

**Q9 超过 3 次**
用户选 B：直接禁止开始该内容，但入口不置灰；点击后弹出提示。服务端也要拦。

**Q10 历史 baseline**
用户选 C 改良版：星星按每个内容的历史最好成绩折算，但打卡日期不补，打卡从 v0.4 上线后记录。

**Q11 曲线**
用户选 B：当月每日账户总余额；默认当月，可切换其他月份，暂时支持最近 1 年。

**Q12 月历**
用户选 A：打卡 ✓ + 当天星数；练过但没完整练完浅色圆点；需要看原型。原型确认后选 A 方案。

**Q13 路由**
用户选 A：`/` 改为我的成长，教材内容列表迁到 `/units`，侧边栏第一项是成长页。

**Q14 次数显示**
用户确认：只在超过 3 次时弹提示，列表和详情平时不显示次数。

**Q15 等级**
用户选 A：只显示累计星星；等级和宠物形象后续再定。

### 第三轮

**Q16 上线前月份**
用户选 C：过去月份只显示日历，不显示曲线；等上线后有真实打卡记录，再支持回看「历史成就」。上线前月份显示「打卡记录从 2026 年 11 月开始」。

**Q17 拦截位置**
用户选 C：内容卡片点击和「开始跟读」都拦截；服务端兜底。用户同时提出要做站内弹窗 UI，不再用浏览器原生弹框。

**Q18 未读完结束页**
用户选 B：保持简单，收尾页照常显示本次句子星，加标注「未读完所有句子，不能累计星星🌟哦！」；保留「再练一遍」，孩子想拿星会点它。

**Q19 未完成日**
用户选 A：浅色小圆点，不显示数字；日历下方图例说明「练习过 · 未完成整条内容」。

**Q20 成长页模块**
用户选 A：累计星星 + 连续打卡 + 月历 + 余额曲线。

**新需求：星星翻倍**
如果一轮里 90% 的句子（四舍五入）得到 3 星，则本轮星星值翻倍。例：15 句里 14 句 3 星、1 句 2 星 → `(14×3+2)×2 = 88`。结束页提醒「读得太棒了🎉这次星星翻倍啦！共获得 88 🌟！」，不展示计算公式。

### 第四轮（本轮）

**Q21 句格显示**
用户问：一个句子 1 星 → 3 星 → 2 星，句格显示最高星还是最新星？

结论：

- 当前代码：句格显示历史最高星（3）；即时评分卡显示本次录音星（2）并显示「最好成绩 X 分」。
- 建议保持句格显示最高星，与账本「每句本轮最高星」一致；即时卡补「本句最好 ★★★」，让孩子知道最高星没丢。
- 账本计算不受影响：同一 run 内该句按 3 星计入。

**原型选择**
三个布局方案中，用户选 A「仪表盘」：顶部三张统计卡 + 标准月历 + 余额曲线。

**第四轮确认**
用户确认：句格与即时评分卡保持现有 UI，不额外加「本句最好」提示；其余 3 项按建议定；开始写 spec。

## 4. 事实与数据

- 现有 `practice_attempts` 共 180 条，时间 2026-10-20 至 2026-11-04。
- 账号：管理员 `424…`，家长测试号 `01f…`，另有 36 条 `owner` 为 NULL 的账号体系前记录。
- 按「每个内容历史最好星」折算的 baseline：`01f…` 约 95 星，管理员约 75 星，NULL 记录约 35 星。
- 大部分历史轮次并不完整（例如 6 句内容多数轮次只覆盖 1–4 句）。严格按「完整练习」回填只有约 2 个打卡日；这正是 baseline 只折算星星、不补打卡的原因。
- 当前代码的句格用 `localBest`（每句最高分）显示；即时评分卡用 `result.stars`（本次星）显示。账本将复用「每句本轮最高星」的口径。

## 5. 确认结果

1. **句格/即时卡星级显示**：保持现有 UI——句格＝历史最高星；即时评分卡＝本次录音星 + 最好成绩；不额外加提示。
2. **内容卡片口径**：改读账本最近一次完整练习的入账星（含翻倍）；没有完整练习显示「还没完整练过」。
3. **初始星星日期**：记在上线当月 1 日，作为当月曲线起点。
4. **NULL 归属**：2026-10-20 的 36 条旧记录（约 35 星）并入管理员账号。

## 6. 明确不做 / 延后

- 今日任务看板、任务生成、家长布置任务。
- 宠物 UI、宠物动画、等级/称号（0.4.x；账本和余额已能支撑阈值判断）。
- 多孩子/孩子档案切换。
- 星星消费、商城、排行榜。
- 一次性替换全站原生确认框（v0.4 只做超次数弹窗）。

## 7. ADR 候选

这套积分规则满足 ADR 的三个条件：难回退（账本 schema 和统计口径）、反直觉（按轮而非按句、每周上限、翻倍）、真实取舍（按次累加可刷星，按历史最好星会封顶）。建议补 `docs/adr/0006-star-accounting.md`，记录为什么采用「按完整练习入账 + 每周上限 + 翻倍 + 初始星星」。spec 定稿后可一起落。
