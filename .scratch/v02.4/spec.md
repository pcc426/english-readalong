# Spec: V0.2.4 校对体验打磨（标题可改 / 末句直发 / 退回校对）

用户完整实测 V0.2.1–V0.2.3 后的反馈（2026-10-27），五点全部确认。

## 决定

1. **确认按钮文案**：确认后显示「本句已确认 ✓」，去掉括号说明。→ 票 01
2. **右栏提示收敛为一个 banner**：「教材原文加载失败」「句子已增删，请手动对照复制」「保存中…/已保存 ✓/保存失败」「操作失败」等全部收敛到右栏顶部同一个 banner 槽位，只显示最新一条；卡片头部与底部的散落提示移除。右列加宽 26rem→30rem。→ 票 01
3. **末句直发**：最后一句时【下一句】按钮变为【定稿发布】——全部句子已确认即亮起，未确认置灰并提示剩余数；发布成功后展示已发布态与「去练习」入口。→ 票 02
4. **校对页可改标题**：草稿标题在校对页可编辑（PATCH /api/drafts/[id]），发布时以最新标题为准（buildContentPack 已取草稿标题）。→ 票 03
5. **退回校对（unpublish）**：已发布内容，发布者可退回 proofreading：
   - 清空该内容**所有账号**的练习记录（句子结构可能变化，旧进度错位，保留有害——用户明确要求清空）
   - 删除已发布内容包文件（从所有账号的列表与练习中消失，直到重新定稿；同 id 重发后练习链接不变）
   - 草稿句子原样保留，只需改错的句子并重新确认、定稿
   - 仅发布者本人可操作（custom=归属账号 / standard=制作的管理员）；强确认提示写明清空后果
   - → 票 04

## 明确不做

- 不做其他账号的练习记录保留/迁移（清空是明确决定）
- 不做撤回后的自动通知
- 不改转写缝与评分缝

## 基线

398 测试全绿；每票只增不减；typecheck + build 必须通过。
