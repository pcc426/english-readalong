# V0.3.6 规格：教材内容可见性开关

状态：已验收（2026-11-04），待提交/部署

## Problem Statement

标准内容（教材内容）目前是「所有账号可见」：管理员制作的教材素材定稿后，会立刻出现在每个家长账号的「教材内容」页，视频也对任何登录账号放行。

但监管与版权上存在风险：部分标准内容素材并非本项目自制，而是取自其他创作者；把这类视频向所有家庭公开传播，可能涉及侵权或需要相应资质。用户希望暂时下架这类内容的公开可见性，但保留管理员继续制作与自用的能力，并保留未来一键恢复公开的余地。

当前系统没有「标准内容对谁可见」这个维度：标准内容包不记录上传者，可见性写死在加载缝里（标准全部公开 + 本账号自定义），也没有任何全局设置存储。

## Solution

新增一个全局开关「教材内容对家庭账号开放」，由管理员在管理页切换，默认关闭。

- **关闭时（默认）**：家庭账号（非管理员）完全看不到「教材内容」入口、标准内容列表、标准内容详情、标准教材视频与教材原文；只能看到和使用自己的自定义内容。管理员不受影响，仍可看到「教材内容」、制作标准内容并练习标准内容——即标准内容只对管理员可见。
- **开启时**：恢复当前行为，标准内容对所有账号可见。
- 开关保存在数据库里，管理员可在站内随时切换，不需要改环境变量或重启服务。
- 关闭开关不会删除任何内容、草稿、素材或练习记录；重新开启后，原有练习进度照常显示。

## User Stories

1. As a 管理员，I want to 在管理页打开或关闭「教材内容对家庭账号开放」，so that 我可以在版权问题未解决时先收紧传播范围，问题解决后再恢复。
2. As a 管理员，I want to 在开关默认关闭时仍能进入「教材内容」并看到全部标准内容，so that 我可以继续检查、制作和自用教材素材。
3. As a 管理员，I want to 继续使用标准内容的上传、转写、校对、预览、定稿、退回校对和删除流程，so that 下架公开可见性不影响内容制作能力。
4. As a 管理员，I want to 在管理页和标准内容制作页看到当前可见性状态，so that 我不会误以为内容已经对家庭开放。
5. As a 管理员，I want to 切换开关后立即生效、无需重启服务，so that 我可以在需要时快速收紧或恢复。
6. As a 管理员，I want to 看到切换成功或失败的明确反馈，so that 我知道设置是否真的落库。
7. As a 家长账号，I want to 在开关关闭时看不到「教材内容」入口，so that 我不会误入已经下架的内容区。
8. As a 家长账号，I want to 在开关关闭时登录后直接落在「自定义内容」，so that 我仍能正常使用自己上传的内容。
9. As a 家长账号，I want to 在开关关闭时直接访问教材内容页或标准内容详情时得到「不存在」而不是能继续播放，so that 下架是真正生效的，而不只是隐藏了入口。
10. As a 家长账号，I want to 在开关关闭时无法通过接口列表、详情、练习或媒体地址拿到标准内容，so that 知道内容 id 或视频地址也不能绕过限制。
11. As a 家长账号，I want to 在开关关闭时自己的自定义内容列表、详情、练习、视频播放完全不受影响，so that 收紧标准内容不会误伤我的私有内容。
12. As a 家长账号，I want to 在开关重新开启后重新看到「教材内容」入口和标准内容，so that 公开恢复时不需要做任何额外操作。
13. As a 家长账号，I want to 在开关重新开启后保留之前的标准内容练习记录，so that 进度不会因为一次下架而丢失。
14. As a 孩子，I want to 在开关关闭时只能练自己家的自定义内容，so that 家庭练习仍可继续。
15. As a 管理员，I want to 开关只影响「标准内容」，不影响任何账号的自定义内容，so that 内容边界保持清晰。
16. As a 管理员，I want to 在关闭状态下仍然能通过自己的账号播放标准教材视频，so that 制作和校对时素材可用。
17. As a 管理员，I want to 标准内容制作完成后按当前开关状态决定是否对家庭开放，so that 不会因为忘记切换而意外公开。
18. As a 管理员，I want to 开关状态持久化在数据库中，so that 服务重启、重新部署后状态不会丢失。
19. As a 管理员，I want to 旧数据库升级到本版本后自动获得这个开关（默认关闭），so that 不需要手工迁移。
20. As a 管理员，I want to 非管理员无法读取或修改这个开关，so that 可见性策略只能由管理员决定。
21. As a 系统维护者，I want to 所有可见性判断收敛在一个入口，so that 列表、详情、练习、媒体各处的行为不会漂移。
22. As a 系统维护者，I want to 这次变更是纯访问控制、不改内容包结构，so that 已有标准内容与自定义内容数据保持兼容。
23. As a 家长账号，I want to 在开关关闭时即便浏览器里还留着旧地址，也不会看到标准内容，so that 下架口径一致。
24. As a 管理员，I want to 在开关关闭时管理页明确写清「仅管理员可见」，so that 我对当前对外状态一目了然。

## Implementation Decisions

### 开关的存储与语义

- 新增一张全局设置键值表（`app_settings`：键、值），随数据库初始化创建，旧库自动补建；不引入迁移框架。
- 唯一设置键为 `standard_content_public`，值为 `"1"` / `"0"`；**键缺失一律视为关闭**。这样新库、旧库、异常库的默认行为都是收紧后的状态。
- 开关存数据库而不是环境变量：管理员需要在站内随时切换，且状态要跨重启、跨部署保留。
- 开关语义是「标准内容对家庭账号开放」。关闭时，标准内容只对管理员可见。当前只有一个管理员账号，因此不做「仅上传者本人可见」的细分；多个管理员之间共享标准内容可见性。（上传者级隔离见 Out of Scope。）

### 可见性判定的唯一入口

- 新增内容可见性设置模块，提供三个能力：
  - 读取当前开关（缺省关闭）；
  - 管理员设置开关；
  - 判定某账号能否看标准内容：`是管理员 或 开关已开启`。
- 所有后端闸门与前端下发都从这一个判定派生，避免列表、详情、练习、媒体各写一套。
- 判定函数同时接受账号与数据库连接，保持与现有鉴权守卫一致的调用方式。

### 前端入口

- 当前账号信息接口在返回账号时，额外返回一个布尔值 `standardContentVisible`（由上述唯一入口计算）。壳层据此决定是否渲染「教材内容」入口；管理员恒为可见。
- 侧边栏：`standardContentVisible` 为假时，不渲染「教材内容」；「自定义内容」保留。管理员的管理入口不受影响。
- 非管理员在关闭态直接访问根路径（教材内容首页）时，由壳层重定向到「自定义内容」。标准内容详情页不单独重定向，由服务端按不存在处理。
- 管理页新增「教材内容可见性」区域：显示当前状态、提供开关、说明关闭时家庭账号看不到教材内容和教材视频，并给出保存成功/失败反馈。开关默认关闭。
- 管理页与标准内容制作页的文案从「定稿后全账号可见」改为「定稿后按可见性开关对家庭账号开放」，并显示当前是「仅管理员可见」还是「对家庭账号开放」。

### 后端闸门

关闭态下，非管理员访问标准内容统一被拒；管理员与自定义内容不受影响。

- **教材内容列表**：非管理员返回 403，错误码 `STANDARD_CONTENT_DISABLED`。
- **标准内容详情**（页面数据与服务端渲染共用同一归属/可见性函数）：非管理员按不存在处理，返回 404 / `notFound()`，不暴露内容是否存在。
- **练习提交**：非管理员对标准内容返回 404，且不调用评测服务（不浪费讯飞调用）。
- **媒体接口**：关闭态下，非管理员访问被标准内容包引用的视频与封面（包括随代码素材与运行时标准素材）一律 404；本人账号目录下的自定义视频/封面照常放行。
- **教材原文查询**：关闭态下非管理员拒绝（该接口只服务于标准内容校对流程）。
- **自定义内容全链路不变**：列表、详情、练习、媒体、定稿、退回校对都维持现状。
- **管理员标准内容制作链路不变**：上传、转写、校对、预览、定稿、退回校对、删除均不隐藏、不改变。

### 数据与兼容

- 内容包 schema 不变：标准内容包仍不归属账号，不新增上传者字段。
- 已发布的标准内容、随代码标准内容、管理员运行时标准内容都不迁移、不删除。
- 关闭开关不清理任何练习记录；重新开启后按原账号继续显示进度。
- 本版本不改内容加载缝的「标准 + 本账号自定义」合并规则，只在读取结果之上加可见性闸门。

### 错误语义

- 列表与教材原文这类「功能整体关闭」的入口用 403，错误码 `STANDARD_CONTENT_DISABLED`。
- 详情、练习、媒体这类可能被直接寻址的入口用 404，避免向非管理员暴露内容 id 或文件是否存在。

## Testing Decisions

- 好测试只断言外部行为：给定开关状态与账号角色，HTTP 接口返回什么；不断言内部函数调用或实现细节。
- 复用现有认证测试原语（临时数据库、临时内容目录、普通/管理员会话 cookie），沿用现有路由测试的写法。
- 新增内容可见性设置模块的单元测试：
  - 键缺失时判定为关闭；
  - 设置为开启后可读回开启，跨连接持久；
  - 管理员即使开关关闭也判定为可见。
- 路由级测试（普通账号与管理员成对覆盖）：
  - 教材内容列表：默认关闭时普通账号 403、管理员 200；开关开启后普通账号 200。
  - 标准内容详情：关闭时普通账号 404；管理员 200；本人自定义内容普通账号 200。
  - 练习提交：关闭时普通账号对标准内容 404，且不触发评测；管理员与自定义内容不受影响。
  - 媒体接口：关闭时普通账号访问随代码标准视频/封面 404、运行时标准视频/封面 404；本人自定义视频 200；管理员访问标准视频 200。
  - 管理开关接口：非管理员 403；管理员可读取默认关闭、写入开启并读回；非法请求体 400。
  - 当前账号接口：普通账号默认 `standardContentVisible=false`；管理员恒为 true；开关开启后普通账号为 true。
- UI 走手工验收清单（沿用本仓库对页面不做自动化测试的约定）：管理页开关、侧边栏隐藏、根路径重定向、标准内容制作页状态文案、iPad/桌面两种宽度。
- 回归基线：`npm test` 现有 603 条只增不减，`typecheck`、`build` 全绿。

## Out of Scope

- 上传者级别的标准内容隔离（多管理员时谁能看谁上传的内容）。
- 隐藏或删除管理员的「标准内容制作」功能。
- 对已下载/已缓存的视频做撤回、水印、DRM 或审计日志。
- 按单条内容、按账号或按时间段的细粒度开关。
- 环境变量或命令行开关（本次只做站内管理页开关）。
- 修改内容包 schema 或迁移已有标准内容包。
- 家长账号自行申请或订阅标准内容。

## Further Notes

- **部署后默认关闭**：v0.3.6 上线后，家庭账号会立即失去「教材内容」入口，直到管理员在管理页打开开关。这是本次需求的核心效果，需要在上线说明里明确写出。
- 开关是访问控制，不是数字版权保护：已经在设备上下载或浏览器缓存过的视频无法被本次改动收回。
- 关闭期间管理员仍可通过自己的账号完整体验标准内容，便于继续制作和验收。
- 与 ADR-0002（公网无鉴权防火墙的早期决策）和 ADR-0003（邀请制账号与会话）保持一致：所有闸门仍以登录会话为前提，只是叠加标准内容的可见性判断。
- 版本归属：本规格对应 v0.3.6，属于小迭代，单票实现即可。
